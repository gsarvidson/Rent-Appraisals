## Current state of discussion

The channel was created on 11/06/2026 to scope a **rent appraisal tool** for Trade Me Property. Early discussion centres on the value proposition, target users (property managers / rental offices), data advantages, and how to package and monetise it. The scoping conversation has been formalised into a Jira epic ([TPR-1 Rental Appraisal tool](https://trademe.atlassian.net/browse/TPR-1), created by Nick Connor from Glen's kick-off message, currently **Backlog** and unassigned). No further channel activity since 12/06/2026.

## Key themes

**Demand validation.** Glen reports that every rental office and PM spoken to about a rent appraisal tool has been interested — seen as a quality, time-saving tool that adds value to their businesses. A [Figma prototype](https://energy-doge-64944771.figma.site/) exists.

**Use case.** The core use case is leverage to win a landlord, during lease renewals, and potentially a bulk option (API) for valuing a whole rent roll. The report could be shared with landlords/tenants or used in GTM conversations.

**Data moat.** Trade Me's advantage is its held leased data that PMs can't access themselves — that's seen as the best unlock. Extras like supply/demand data and projected values are "nice to haves" but reasonable data moats. MBIE bond data is already ingested/reported in PBI and is public, but quite delayed.

**Where it could be built.** Options floated: Homes already has rent-pricing logic (not bad); could build within PBI; or build greenfields outside OneHub.

**Packaging / monetisation.** Seen as logical to reserve as a Premium Partner benefit (Glen argues it aligns to the leads partnership — F28). Idea floated: bundle with Premium PA as a basic version, and a future **Prem+ PA** as the AI-enhanced version delivering leads etc. Glen is unsure a "smarter/more accurate appraisal" is the real value — PMs may just want quick and easy. Prem+ might instead unlock API access or unlimited use. Nick agrees a **usage cap** is the more attractive lever — it would simplify build complexity, making it the current front-runner for how tiering works.

## Open questions raised (by Nick Connor)

- Is there a need to protect/log access to the tool? (Glen: yes)
- What's the difference between the on-screen version and the "full report" generated on click? (Glen: unsure — to confirm)
- How can we tell a home is renovated? (Glen: beyond MVP; would love owner-updated info, PM site-visit input, inference from uploaded photos)

Still unresolved: where the tool gets built (Homes logic vs PBI vs greenfields), whether it lands in F28 leads partnership or Premium PA, and who owns TPR-1 (still unassigned in Backlog).
